EduTrack Pro Documentation

Welcome to your platform documentation hub. Explore step-by-step guidance below to fully utilize the platform's features.

  • 1
    Toggle between the Login or Register fields inside the initial startup window card.
  • 2
    New registrations require completing Full Name, email authentication mapping, and setting up an account password.
  • 3
    Upon registering, choose the parameters of subjects you teach inside the selection interface grid and hit Save & Continue to finalize validation parameters.
  • 1
    Navigate to the Students tab using your main app control tab panel.
  • 2
    Manual Upload: Input the student full title name alongside their corresponding parent WhatsApp parameters, then save.
  • 3
    Automated OCR Scan: Hit the Upload Registry Image dashboard area. Choose a clear snapshot from the device memory. The internal processing engine runs text reading workflows automatically to generate user accounts instantly.
  • 1
    Access the Marks tab interface to open global target lists.
  • 2
    Use the dropdown menus to select the specific evaluation tracking timeline constraints (e.g., Month and Exam type profiles).
  • 3
    Input grades manually or select Scan Marksheet Image via OCR to map values automatically from image documents. Click Save Grades.
  • 4
    Select Flag Failures to filter out metrics below 40%. Click Send Alerts to Parents to quickly notify parents via WhatsApp.
  • 1
    Open the Tasks page to reveal current progress matrices.
  • 2
    Choose the current Subject target parameter to populate the active rows. Use the Add Manually function if you need to adjust subject parameters.
  • 3
    Tap the green checkmark icon to confirm correct execution or the red "X" icon to log a failed attempt. The system automatically syncs changes to Firebase.
  • 4
    Logging consecutive errors automatically copies a pre-formatted notification message and redirects you to WhatsApp to alert parents.
  • 1
    Head over to either the Dashboard Quick Board module or the dedicated Homework section tab.
  • 2
    Click Voice Input / Dictate. Speak into your microphone using Sinhala text articulation (`si-LK`) to watch your text generate live.
  • 3
    Tap Broadcast / Share via WhatsApp to copy the organized text format layout structure to your clipboard and open your messaging dashboard.
  • 1
    Navigate to the Schedule section block area panel.
  • 2
    Click the upload layout panel card area and supply a screenshot image file of the class master program.
  • 3
    The OCR engine extracts timetable configurations from text characters and updates the interface cards. Click Save Schedule Grid to lock structural data in the cloud database.
  • 1
    Open the Groups management interface screen.
  • 2
    Paste your standard target class room link URLs inside the text areas mapped to sections A, B, C, and D.
  • 3
    Click Apply Changes. This saves your communication pathways, ensuring smooth messaging throughout the platform.
